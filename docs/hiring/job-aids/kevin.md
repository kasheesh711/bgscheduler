# Job aid: Kevin (owner)

One page. Open https://bgscheduler.vercel.app/hiring. The Overview opens first.

## Task 1. What is the conversion from each stage to the next?
1. Stay on the **Overview** tab.
2. Find **Hiring funnel and pipeline**.
3. Read the table with the caption **Funnel steps**. Its rows are: Applied, Contacted, Replied to pre-screen, Onsite invited, Visit booked, Visited, Offer.
4. Read **From step before** for each conversion rate.
5. To compare, select a campaign or "Applied in week N of YYYY" in **Show**.

## Task 2. How many candidates are stuck, and where?
1. On the same panel, read the table with the caption **Candidates by current stage**.
2. Read the **Stuck** column. The rule ("after N days") shows beside each count.
3. Click a stuck count. The candidate table under the meters, above the charts shows only those candidates.
4. Read **Next action** and **Owner** for that stage. Tell the owner.

## Task 3. How long do candidates spend in each stage?
1. In **Funnel steps**, read **Time from step before** (median days, and p90: 9 in 10 candidates take this long or less).
2. In **Candidates by current stage**, read **Days in stage**.
3. "few" after a count means fewer than 5 cases. The median can move a lot.

> **What "Needs review" means**
> The app does not have the data to show a field. It does not guess. The words after "Needs review:" give the reason. On this panel, it means the page read only the most recent candidates, so counts can be low.
