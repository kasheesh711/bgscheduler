# Job aid: Admin (Aya and Thea)

One page. Open https://bgscheduler.vercel.app/hiring. The Overview opens first.

## Task 1. Which paper do I print for each visit tomorrow?
1. Click the **Visit day** tab.
2. Click **Aya: print list**.
3. Find the **Tomorrow** heading.
4. For each row, click **Print <paper name>** in the **Paper** column. The file opens. Print it.
5. If **Tomorrow** shows "No visits.", nothing needs printing for tomorrow. The list also shows each later day with a visit, up to 8 days ahead.

## Task 2. Which room is each visit in?
1. On **Aya: print list**, read the **Room** column.
2. Today, every row shows "Needs review: no room is booked for this visit". The app does not store rooms yet.
3. Agree a free room with Kevin before the visit. Write it on the printed paper.

## Task 3. Which visits have no paper ("Needs review")?
1. On **Aya: print list**, read the line at the top. It counts the visits that miss a head or a paper.
2. Find each row with "Needs review" in the **Head** or **Paper** column.
3. Read the reason. Example: "Needs review: no question paper for English Language in the paper library".
4. Tell the person in the table below on the same day.

> **What "Needs review" means**
> The app does not have the data to show this field. It does not guess. The words after "Needs review:" give the reason. Do not print or book a room for that field until a person fixes the gap.

## Who to tell

| Gap | Tell |
|---|---|
| Needs review: no question paper (today: English Language, English Literature) | Kevin (paper library), with the head of that subject |
| No mark scheme: marking cannot run | Kevin |
| Needs review: no head takes the subject | Kevin (head roster) |
| Needs review: no room is booked | Kevin. Rooms are not stored yet. |

**Visit day → Message previews** shows the print list as a message. It is a preview only. The app sends nothing. You get no hiring message from the app today, so open this page each afternoon.
