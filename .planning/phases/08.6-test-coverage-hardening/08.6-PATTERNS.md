```typescript
interface FakeDbState {
  activeSnapshotId: string | null;
  selectCallCount: number;
  yieldBeforeResolve: boolean;
}

function makeFakeDb(state: FakeDbState): Database {
  function chain(rowsForLimit: unknown[], rowsForFull: unknown[]) {
    const limitFn = vi.fn().mockImplementation(async () => {
      if (state.yieldBeforeResolve) {
        await new Promise((r) => setTimeout(r, 0));
      }
      return rowsForLimit;
    });
    const whereChain = {
      limit: limitFn,
      then: (onFulfilled: (rows: unknown[]) => unknown) => {
        const p = (async () => {
          if (state.yieldBeforeResolve) {
            await new Promise((r) => setTimeout(r, 0));
          }
          return rowsForFull;
        })();
        return p.then(onFulfilled);
      },
    };
    const whereFn = vi.fn().mockReturnValue(whereChain);
    const fromFn = vi.fn().mockReturnValue({ where: whereFn });
    return { from: fromFn };
  }

  const selectFn = vi.fn().mockImplementation(() => {
    state.selectCallCount += 1;
    return chain(
      state.activeSnapshotId ? [{ id: state.activeSnapshotId }] : [],
      [],
    );
  });

  return { select: selectFn } as unknown as Database;
}
```

**What stays the same:** describe block structure, globalThis reset hooks, fake DB shape, `Promise.all` race pattern.

**What differs (NEW TCOV-01 tests):**

Cannot use the existing `chain([], [])` shape because it returns empty rows for all tables; new tests need a per-table dispatch in `selectFn`'s `.from(target)` callback (the `_target` pattern from `past-sessions-diff-hook.test.ts:75-107` is the canonical way).
2. **`byWeekday` map population test** — fixture with 2 windows on 2 different weekdays + assert `index.byWeekday.get(N)` for each.
3. **Snapshot-active race fallback test** — pre-seed `globalThis.__bgscheduler_searchIndex` with a cached index; configure fake DB to return zero active rows on the cached-check select; assert `ensureIndex` returns the cached index without throwing. (Locks in defensive behavior even though REL-01 closed the race in production.)

**Cross-file dependencies:**
- Imports `SearchIndex` and `Database` from existing modules (no new types).
- The new "buildIndex denormalization" tests need a richer `makeFakeDb` than the current 8.5-02 version. **Recommend:** copy the `_target`-based dispatch pattern from `past-sessions-diff-hook.test.ts:75-107` (see analog below) and adapt — that pattern dispatches by `schema.X` table reference.
