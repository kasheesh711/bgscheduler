# Quick Task 260807-d12: Add MAINTENANCE_MODE kill switch to middleware

## Goal

Give bgscheduler an in-app off switch: block the staff UI while all 15 Vercel crons
keep running. Vercel's Pause Project cannot do this — pausing blocks the production
deployment that the crons target.

Approved plan: `/Users/kevinhsieh/.claude/plans/how-can-i-turn-reactive-snowglobe.md`

## Behaviour matrix

| Surface | MAINTENANCE_MODE=true |
|---|---|
| 25 `(app)` pages + their APIs | 503 |
| `/api/internal/*` (15 crons) | runs normally |
| `/schedule/{token}` (parent links) | renders normally |
| `/login`, `/api/auth/*` | reachable, so a bypass admin can sign in |
| bypass email | full access |
| `/api/line/webhook` | **503 — inbound messages lost, user-confirmed** |

## Task 1 — `src/lib/maintenance.ts` + unit tests

**files:** `src/lib/maintenance.ts`, `src/lib/__tests__/maintenance.test.ts`

**action:** New edge-safe module. Must NOT import `@/lib/env` — that module calls
`getEnv()` at load and throws on a partial environment, and middleware runs on the
edge. Read `process.env` directly, exactly as `src/lib/student-schedule/live.ts:67`
does. Header comment block carrying the `MAINT-01`…`MAINT-05` design IDs, matching
the numbered-ID style of `src/lib/line/schedule-bot.ts:7-22`.

Exports:
- `isMaintenanceMode(raw = process.env.MAINTENANCE_MODE)` — `raw === "true"` exactly.
  Opt-in, fail-open. Deliberately the inverse polarity of
  `ENABLE_STUDENT_SCHEDULE_LIVE`'s `!== "false"`: that flag defaults on, this one
  defaults off, because a typo must never black out production.
- `MAINTENANCE_EXEMPT_PREFIXES` — module-scope `const`: `/api/internal/`,
  `/schedule/`, `/api/auth/`, `/login`. Keep the trailing slash on `/schedule/`;
  it is what keeps the authenticated `/student-schedule` admin page gated.
- `isMaintenanceExempt(pathname)` — prefix match, plus exact match for `/login`.
- `isMaintenanceBypassEmail(email, raw = process.env.MAINTENANCE_BYPASS_EMAILS)` —
  trim + lowercase both sides; unset/empty ⇒ nobody. Mirrors `scheduleBotAdminIds`.
- `maintenanceResponse(pathname)` — 503 + `Retry-After`. JSON for `/api/`,
  inline-styled HTML otherwise (no Tailwind — this response never loads the app shell).

**verify:** `npx vitest run src/lib/__tests__/maintenance.test.ts`

**done:** Polarity cases (unset/`"true"`/`"false"`/`"TRUE"`/garbage), every exempt
prefix hits, near-misses miss (`/student-schedule` gated, `/schedule/abc` exempt),
allowlist parsing (unset, whitespace, case, multi-entry), response shape both ways.
